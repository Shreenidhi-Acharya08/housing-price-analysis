# Housing Price Analysis

Exploratory data analysis (EDA) on a housing dataset to identify the key features that drive property prices.

## What I did
- Cleaned and preprocessed raw housing data using Pandas
- Performed exploratory data analysis to understand feature distributions and relationships
- Visualized trends and correlations using Matplotlib to identify key price-driving factors
- Summarized insights on which features most strongly influence housing prices

## Dataset
Dataset provided during the Data Science internship at Elewayte (not included here due to data-sharing policy)

## Tools & Libraries
Python, Pandas, Matplotlib, Jupyter Notebook
